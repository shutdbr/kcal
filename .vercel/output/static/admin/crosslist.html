cross-listing

One course, several department codes. The codes decide which programmes a course can count toward; credit sharing decides what happens when it counts toward two of a student's programmes at once.

credit sharing — site default

a course that counts for two programmes e.g. a major and a minor

its credits go to the first programme that claims it — majors before minors before concentrations — so a student must take more courses to finish both. Any course below can override this.
